# КОНТАКТ — CINEMATIC (JavaScript / WebGL 2)

Играбельная пошаговая игра 1 на 1. Проект написан на чистом JavaScript без фреймворков и внешних библиотек; для визуализации использует WebGL 2, а при недоступном WebGL включает запасной программный 2.5D-рендерер.

## Запуск

- **Быстро:** откройте `KONTAKT_CINEMATIC.html` в Chrome, Edge или Firefox. Это самодостаточный файл с CSS и JavaScript внутри.
- **Для разработки:** запустите `npm start` в папке проекта (нужен Node.js 18+) и откройте `http://localhost:5173`.
- **На GitHub Pages:** используйте `index.html` — все зависимости локальные и пути относительные.

## Управление

- `1–6` — прямой удар в челюсть, локоть, колено, подсечка, бросок через бедро, задняя подножка.
- `A / D` или `← / →` — отойти и сблизиться.
- `Пробел` — защитная стойка.
- Кнопка **Кинокамера** переключает динамическое приближение в момент атаки.
- Кнопка **Звук** включает/выключает эффекты WebAudio. Звук включается после первого действия пользователя согласно ограничениям браузера.

## Что сделано

- 3D-сцена с цветным боковым светом, световыми лучами, объёмной геометрией арены, тёмным освещением и цветокоррекцией;
- геометрия торса, лица, ног и предплечий формируется из поперечных сечений вместо одних сфер;
- анимации ударов и шагов, захват и два броска, двухзвенная IK для рук;
- инерция, реакция на попадание, замедление кадра при ударе, падение после KO;
- ссадины и следы попаданий на теле, пятна на покрытии;
- синтезированные звуки ударов, шагов, блоков и падений;
- редактор внешности, бой с ИИ и локальный режим на двух игроков.

## Файлы

- `index.html` — интерфейс;
- `style.css` — оформление и адаптивность;
- `engine.js` — процедурная геометрия, рендерер, камера и сценические эффекты;
- `game.js` — пошаговая логика боя, анимации и звук;
- `server.js` — локальный сервер разработки без зависимостей;
- `KONTAKT_CINEMATIC.html` — версия для быстрого запуска в одном файле.

## Граница качества

Это **стилизованная кинематографичная 3D-графика**, а не фотограмметрия человека. Для реализма уровня больших игровых студий нужны качественные лицензированные персонажи в glTF/FBX, PBR-текстуры, скиннинг, анимации motion capture и отдельный физический движок. Текущая версия остаётся полностью самостоятельной и запускается без сети.
