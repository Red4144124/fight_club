# КОНТАКТ HD — Arcade Bloodline (v0.6)

Переход проекта `fight_club` к качественному **рисованному 2D-файтингу** в эстетике классических аркад. Герои, декорации и визуальные эффекты оригинальные, не копируют персонажей или игровые ассеты предоставленного референса.

## Играть

- **Онлайн / GitHub Pages:** откройте `index.html`, если GitHub Pages настроен на ветку `master` и корень репозитория.
- **Без сборки и интернета:** скачайте `KONTAKT_HD_ARCADE.html` — все изображения, CSS и JS встроены в один файл.
- **Разработка:** `npm install`, затем `npm run dev` (Vite).
- **Проверка TypeScript:** `npm run compile`. Для сборки в `dist/` — `npm run build`.

Файлы `index.html`, `style.css`, `game.js` и `assets/*.webp` достаточно разместить на обычном статическом хостинге. `game.js` компилируется из TypeScript (`src/`).

## Технологии

- TypeScript: типизированные состояния бойцов, дистанция, очередность, урон и статусы.
- Phaser 3.90 + WebGL: если доступен движок с CDN и графическое ускорение, сцена использует Phaser; без сети или WebGL автоматически работает полноценный Canvas 2D-рендерер. Phaser загружается отдельным скриптом, не требуется для автономной версии.
- Canvas 2D overlays: устойчивые к смене позы фингалы, ссадины, кровь на одежде и бинтах, капли и пятна на полу.
- Web Audio API: синтезированные звуки шагов, ударов, блоков и падения, активируются после взаимодействия с игрой.

## Как играть

Режим против CPU или 2 игрока за одним экраном. Выбор клавишами **1–8** или кнопками:

1. Удар в челюсть
2. Локоть
3. Колено
4. Подсечка
5. Бросок (короткая дистанция)
6. Блок
7. Шаг вперёд
8. Отступление

**Подсечка:** при попадании соперник опускается на колено, его незавершённая атака прерывается; в следующем раунде ему необходимо нажать «Подняться с колена» / `R`, потратив ход.

Удар в челюсть накапливает фингалы, локоть и бросок — ссадины; повреждения и кровь сохраняются на бойцах в течение поединка, переходят на бинты атакующего и пол. Реванш сбрасывает всё.

## Структура

- `src/combat.ts` — независимая игровая механика.
- `src/render.ts` — Phaser/WebGL или резервный Canvas-рендер, эффекты повреждений и крови.
- `src/audio.ts` — звук.
- `src/main.ts` — интерфейс, анимация и игровые ходы.
- `assets/` — спрайты и фон.
- `game.js` — скомпилированный, готовый браузерный JS.

## Текущие ограничения

Это **первый игровой срез**, а не завершённый профессиональный файтинг. Позы персонажей — набор из шести ключевых иллюстраций с программными переходами, а не покадровый motion capture. Физика бросков стилизована. Реалистичные сцепления рук/тела, полноценная анимация захватов, реакция ткани и система сохранения пока не реализованы. При подготовке новых спрайт-листов можно заменить графику без переписывания боевой системы.
