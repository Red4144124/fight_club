# КОНТАКТ: BLOODLINE / v0.5

Браузерный пошаговый файтинг 1 на 1 на **JavaScript + WebGL 2 + Web Audio**. Персонажи созданы процедурно, без внешних 3D-ресурсов и зависимостей. Предусмотрен CPU-рендерер с 2.5D-контурной отрисовкой для устройств, на которых WebGL 2 отключён.

## Как запустить

- **Быстрый запуск**: откройте `KONTAKT_BLOODLINE_v5.html` в браузере (самостоятельный файл; не нужно устанавливать Node.js).
- **Проект для разработки**: `npm start` и откройте `http://localhost:5173`. Нужен Node.js версии 18+; зависимости не требуются.
- `npm run check` проверяет синтаксис JavaScript.

## Игра

- Режим против компьютера и локальный бой двух игроков на одном устройстве.
- Редактор: класс, телосложение, причёска, цвет глаз, кожи и экипировки.
- Приёмы 1–6: прямой удар в челюсть, локоть, колено, низкая подсечка, бросок через бедро, зацеп / подножка.
- Движение: **A / D** или кнопки «Отойти» / «Сблизиться». **Пробел** — защита.
- Удары зависят от дистанции; броски доступны только после сближения.
- Удачная подсечка или зацеп укладывают бойца **на одно колено**: его оставшаяся в обмене атака срывается, а следующий ход расходуется на **подъём**. При необходимости появится кнопка «Подняться с колена».
- Повреждения накапливаются до конца поединка: **фингал после попаданий в голову**, ссадины на лице и конечностях, пятна крови на одежде и на кулаках атакующего, капли и следы на полу арены.
- В редакторе нажмите «Показать фингал и кровь», чтобы увидеть повреждения на модели без начала боя.
- Нокаут завершается анимацией падения; реванш полностью сбрасывает здоровье и повреждения.
- Музыка не используется — звуковое сопровождение создано синтезатором Web Audio. Звук включается после взаимодействия с игрой.

## Структура

- `index.html` — доступный адаптивный UI.
- `style.css` — стили редактора, боевых кнопок и анимации капель.
- `engine.js` — GPU-рендерер WebGL 2, процедурные тела, двухсегментная IK-анимация, повреждения, свет, тени, программный контурный fallback.
- `game.js` — пошаговые правила, AI, дистанция, травмы, подсечка и восстановление, Web Audio.
- `server.js` — локальный веб-сервер без зависимостей.

## Ограничения прототипа

Арт — **стилизованный процедурный 3D**, не фотореалистичная сканированная человеческая модель. Визуальная анимация бросков и нокаутов кинематически управляемая, а не результат полноценной симуляции мягких тканей или motion capture. Для следующего скачка качества нужны художественные меши с UV/PBR-текстурами, риг с весами вершин и профессиональные анимации, экспортированные в glTF.

Для максимального качества рекомендуется актуальный Chrome / Edge / Firefox с WebGL 2. Если браузер блокирует видеоускорение, игра автоматически переходит на совместимый программный рендерер — его картинка отличается.
